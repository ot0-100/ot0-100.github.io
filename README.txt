Life Tracker — библиотека

Библиотека хранит файлы в Supabase Storage, отдельная таблица БД не нужна.
Один пользователь видит только свою папку по user_id.
Максимальный размер файла из интерфейса: 50 МБ.

SUPABASE SETUP

1) Открой Supabase -> SQL Editor.
2) Вставь содержимое supabase-library.sql и нажми Run.
3) Больше ничего в существующем tracker делать не нужно.
4) В сайте войди в аккаунт -> Библиотека -> + Загрузить.

Файлы доступны после входа на любом устройстве. Bucket приватный.
